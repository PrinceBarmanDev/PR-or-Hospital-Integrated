# Presentation notes

## Suggested 8–10 slide order

1. Project title and team members
2. Problem statement
3. Aim and objectives
4. Proposed solution and user workflow
5. System architecture
6. Dataset source, columns and compatibility decision
7. ML approach and actual evaluation (only if valid model was trained)
8. Frontend and backend demonstration
9. Testing, limitations and responsible use
10. Conclusion and future scope

## Live demonstration order

1. Open the frontend using Live Server.
2. Show the dashboard and explain the four inputs.
3. Demonstrate the decorative barbell preview.
4. Submit an example request.
5. Show the API response or explain why model inference is unavailable.
6. Explain dataset compatibility and actual model metrics, if supported.
7. Explain limitations.

## Important wording

This is an academic software prototype. Its output is not medical advice, a diagnosis, coaching guidance, injury prevention, or proof that a lift is safe. Report only actual measured results.
