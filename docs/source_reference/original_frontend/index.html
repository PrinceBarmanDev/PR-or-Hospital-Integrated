How to load: Heaviest plates first (inside), lightest last (outside). Always put collars on. Example: For 100 KG → Bar 20 KG + 40 KG per side = 25 + 15 on each side.

⚠️ Safety: Never load one side only - bar will tip. Always load both sides equally. If you can't lift bar with collars, ask spotter.

Example: Last best 100kg, trying 110kg = 110% - harder, higher risk.
