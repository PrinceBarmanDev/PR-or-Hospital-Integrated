PR OR HOSPITAL — NS REFINED FRONTEND

This package keeps the visual direction and page structure from “For Modification NS.rar”.
It updates the typography and explanatory copy, removes the requested daily tip, and refines
the “04 / THE PROCESS” section.

BAR LOADER
- The bar uses a 20 kg barbell.
- The selected total weight is split equally across both sides.
- Plates are calculated from 25, 20, 15, 10, 5, 2.5 and 1.25 kg denominations.
- The largest plate is placed closest to the bar, matching the original first archive.
- The plate breakdown and per-side total update when the target weight changes.

FILES
- index.html
- styles.css
- script.js

RUN
Open index.html in a browser for the frontend. The prediction/check-my-lift action expects
the API service at http://127.0.0.1:8000, as configured in script.js. This archive contains
the NS frontend files only; it does not include the backend from the first archive.
